# تسليم إصلاح ٤ب — تحقق محلي فقط

تشغيل الفحوص: `node --test tests/day4b-local.test.cjs`.

تستخرج الاختبارات الدوال الفعلية من الصفحة وطبقة البيانات، وتحقن واجهة ومعاملات وملفات وهمية. لا تُحمّل وحدة Firebase ولا تتصل بها. تُستخرج كتل JavaScript المضمنة ونسخة `data-store.mjs` إلى مجلد مؤقت خارج المستودع لفحص `node --check` فقط.

تغطي الفحوص التحليل النقي والتطبيع والالتباس والرؤوس والأوراق، وتعارض الرقم وإعادة callback المعاملة، وتأخر القائمة المحلية، والفشل الجزئي والتأكيد المزدوج وحدّي ٤٥٠/٤٥١، وتبديل السياق أثناء القراءة والمعاينة والحفظ. وتشمل الأيام الفارغة والتنسيق وتصدير الأعداد الأصلية، ومقارنة حسابات وعرض الرئيسية والتقرير والإنتاج اليومي ومسار الاستيراد القديم للبرنامجين الآخرين مع `HEAD`.

قيد Sol المتبقي: معاملة خلو مستند الرقم تمنع هذا المستورد من استبدال مستند موجود فقط. لا تضمن تفرد الاسم المطبع بين جهازين يستخدمان رقمين مختلفين، ولا تحمي من كتابة لاحقة غير مشروطة عبر مسارات الحفظ القديمة. يوجد اختبار يثبت نجاح إنشاء اسمين متطابقين بعد التطبيع برقمين مختلفين؛ لا يدّعي ضماناً غير موجود.

قرار المدير المعتمد: تفرد الاسم الذري بين الأجهزة مؤجل ضمن ق٢ (مشرف واحد، جهاز واحد). يبقى هذا القيد في متابعة المدير؛ لم يُبنَ فهرس أسماء أو قفل، ولم تُغيّر الإضافة اليدوية. اختيار أول ورقة ذات رؤوس مكتملة مطبق وفق القرار المعتمد.

هذه فحوص بمحاكاة محلية، وليست تجربة اتصال أو مراجعة اعتماد. يلزم إعادة مراجعة Argon ثم Sol، وتحديث الخطة بيد المدير. لا يعني إنجاز الإصلاحات اعتماد اليوم ٤ب.
